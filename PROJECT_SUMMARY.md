# Attendance System - Complete Project Overview

## ✅ All Features Implemented

### **1. User Authentication & Role-Based Access**
- Login with email/password (Firebase Auth)
- Signup with role selection (Student/Teacher)
- Role-based navigation to appropriate home screens
- Logout functionality

### **2. Teacher Features**

#### a) QR Code Generation
- Teachers can add/manage subjects
- Each subject gets a unique QR code
- QR data format: `subject_id:subject_name`
- Delete subjects functionality
- Visual display of QR codes for printing/sharing

#### b) Attendance Tracking
- View comprehensive list of students per subject
- See how many times each student marked attendance
- Student email displayed with attendance count

### **3. Student Features**

#### a) QR Code Scanning
- Scan QR codes generated by teachers
- Automatic attendance marking upon successful scan
- Prevents duplicate attendance in same day
- Real-time feedback (success/already marked)

#### b) Attendance History
- View personal attendance records
- Grouped by subject
- Timestamp for each attendance entry
- Historical tracking

## 🗄️ Firestore Collections Structure

### **Collection: `users`**
```json
{
  "email": "student@example.com",
  "role": "student",           // "student" or "teacher"
  "createdAt": timestamp

```

### **Collection: `subjects`**
```json
{
  "id": "auto-generated",
  "name": "Mathematics",
```

```json

  "id": "auto-generated",
```

## 📌 Technical Details

### **QR Code Format**
- Uses `qr_flutter` package
- Data: `{subjectId}:{subjectName}`
- Version: Auto-scaling
- Size: 200x200 pixels

### **Camera Permissions**
- Android: `android.permission.CAMERA` added to manifest
- Mobile Scanner handles permission requests at runtime

### **Duplicate Prevention**
- Attendance checked per student per subject per day
- Prevents same student marking attendance multiple times

### **Database Queries**
- Indexed by `teacherId` for teacher subjects
- Indexed by `studentId` for student attendance
- Indexed by `subjectId` for subject-level attendance
